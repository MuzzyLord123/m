# Photographs go here, one folder per job. Folder name = the project slug.
#
#   public/photographs/external-masonry-and-windows/before.jpg
#   public/photographs/external-masonry-and-windows/after.jpg
#
# Two rules, and the build enforces both:
#
#   1. A before and an after must be THE SAME VIEW. Same spot, same framing,
#      same rough distance. Two photographs of different walls presented as a
#      comparison reads as a con, and the entire design depends on this being
#      honest.
#
#   2. Every photograph needs one line of alt text describing the work shown.
#      Not "image1". The build refuses anything that looks like a filename.
#
# Export them from the WordPress media library at ORIGINAL resolution before the
# old site is switched off — see MIGRATION.md. Do not save them off the live
# pages: those are cropped and re-encoded copies.
#
# Nothing from wp-content/themes/decorator-pro/images/ belongs here. That is the
# bought theme's stock photography of other people's work.
